# 内容组织与成品标准

第2步做材料初查并拟定页面主题，第4步完整应用。先按用途组织内容；数据与计算规则仅在涉及量化内容时应用。内部检查记录不直接复制进正式文稿。

## 按用途组织内容

明确听众需要理解、学会、相信或采取什么行动。按受众的已知信息与演示时长决定深度，每页承载一个主旨；结构服务于目的。以下是可调整的叙事骨架，不是必填章节：

| 用途 | 适合的内容顺序 | 适合的收尾 |
|---|---|---|
| 工作/项目汇报 | 背景与目标→进展与成果→问题与依据→计划与支持需求 | 结论、行动与待决事项 |
| 产品介绍/发布 | 用户场景与问题→产品主张→关键功能与体验→演示或案例→使用方式 | 体验、试用或使用引导 |
| 技术方案/售前 | 需求与约束→方案原理→架构/流程→接口与实施→验证与交付边界 | 推荐方案、实施步骤与待确认项 |
| 培训教学/科普 | 学习目标→概念→示范与案例→练习→反馈与回顾 | 要点、练习或延伸学习 |
| 学术/研究 | 问题与相关工作→方法→结果→讨论与局限 | 结论、开放问题与后续研究 |
| 路演/提案 | 问题与机会→主张/方案→证据与差异→实施与资源 | 具体请求与下一步 |
| 故事/人物/文化分享 | 情境与人物→发展与冲突→转折→结果与意义 | 点题、感悟或开放式思考 |
| 活动/主题演讲 | 主题与共鸣→核心观点→案例或故事→互动与启发 | 主题呼应或行动邀请 |
| 数据分析/经营复盘 | 决策问题→数据边界→指标现状→对比/驱动→诊断与建议 | 有依据的决策与验证计划 |

混合用途可组合，但只保留服务主题的部分。教学不必有管理摘要，产品介绍不必有KPI，故事分享不必有行动计划。已有用户提纲或模板时优先沿用，并指出实质缺口。

非数据主题可以直接使用文字、照片、作品、概念图、流程、案例或练习；没有数字不是材料缺陷。只有内容本身依赖数量证据时，才把缺少数据列为缺口。

## 资料与事实

- 记录所用文件/版本、页面或章节等来源定位。核对专名、日期、术语、引语、产品能力与研究结论；不制造引用。
- 区分来源已证实的事实、用户提供且待核实的信息、建议方案与假设。技术能力、成效或实施承诺不能从设想自动升级为已验证结果。
- 通用知识可用于解释概念；具体、时效或不确定的事实按需查证。用户要求联网核实时使用可用检索工具。
- 用户仅给主题时，可先拟定适合的框架与内容；对缺失的专属信息使用明确待补项，或在确有影响时询问。不要求用户提供与主题无关的Excel或经营数据。
- 真实产品、作品、人物、实验等使用可用的原始素材，保留必要署名与来源。生成插画用于表达概念，不冒充照片证据、产品实拍或实验记录。虚构故事/案例应与真实事实区分。
- 结果、建议和承诺按资料支持的程度表述。研究局限、方案待验证条件及影响结论的信息放在相关页；详细出处可放备注。

## 页面数量与示例

总页数包含实际选用的封面、目录、结尾和附录，不额外加页。按真实内容调整叙事颗粒度，不靠空白页、重复内容或过小字号凑数。

以下12页示例仅演示“摄影入门教学、保留封面、以回顾与练习收尾”的配置，不能套用到所有主题：

| 页 | 页面主题 | 表达形式 |
|---|---|---|
| 1 | 摄影入门 | 原生标题与已确认主视觉 |
| 2 | 学完能做什么 | 学习目标与作品示例 |
| 3 | 拍摄前观察 | 场景、主体与意图 |
| 4 | 曝光基础 | 可编辑概念示意 |
| 5 | 光圈 | 原理与实际照片对照 |
| 6 | 快门 | 原理与实际照片对照 |
| 7 | 感光度 | 噪点与场景选择 |
| 8 | 构图 | 图片与可编辑引导线 |
| 9 | 光线 | 光向与效果解析 |
| 10 | 作品拆解 | 一张真实作品的观察步骤 |
| 11 | 动手拍摄 | 清楚的练习任务 |
| 12 | 回顾与练习 | 要点、作业与反馈方式 |

8页可合并相关概念和案例；16–20页可增加示范、分步讲解或讨论。改变页数时重新分配全部内容。

不设独立封面：直接进入主题，把释放页用于有价值的内容。以独立感谢/Q&A收尾：在总数内留位置，把必要总结并入前面。不设独立收尾：最后一页实质内容承担结束作用，不另加“谢谢”。

## 表达形式

| 内容目的 | 优先考虑的形式 |
|---|---|
| 解释概念/原理 | 概念图、结构示意、类比与简短定义 |
| 教步骤/展示流程 | 可编辑流程图、分步演示、必要截图 |
| 介绍产品/作品 | 真实图片、产品截图、局部细节与场景说明 |
| 比较方案/观点 | 并列对照、比较表、优缺点与选择条件 |
| 讲故事/呈现历程 | 时间线、人物与场景图、转折与重点句 |
| 说明架构/关系 | 原生架构图、关系图、层级与接口说明 |
| 展示研究 | 方法示意、真实结果图表、讨论与限制 |
| 引导实践/互动 | 任务卡、问题、练习与反馈标准 |
| 支持量化判断 | 下述数据规则支持的图表与关键数字 |

每页一个视觉重点，形式随内容变化。图片、引用和大字页可以成为主角，不要求每页都有图表、数字或结论句。

## 涉及数据时：数据与计算

记录来源文件/版本、工作表或页码、期间、粒度、单位、字段与缺失项。检查重复、缺失、异常、聚合重复计数、口径冲突及不完整期间。保留原始文件，清洗与计算在副本中进行。

使用KPI时记录定义、分子、分母、排除条件、期间、单位、目标/方向及来源定位。选择真正影响判断的指标，不为卡片数量凑数。

用户口述数字标为“用户提供”，保留期间、口径及待核实状态，不当作文件验证结果。预览采用的数字也必须先核实；正式分析若改变关键内容，说明变更并按主流程判断是否修订预览。

- 同比/环比变化率=（本期−可比基期）/可比基期；先核对期间长度、范围、币种和定义。
- 15%到18%：增加3个百分点，相对增长20%，不能混写。
- 零/负基期或口径不可比时，报告适合的绝对变化和解释，避免误导增长率。
- 汇总比例通常用总分子/总分母，不能直接平均各组比例。
- 缺失不等于零，未观测不等于无事件，目标不等于实际，样本不代表总体。
- 无去年同期不算同比，无上期不算环比，单期间不编造趋势；改用结构、分布、排名或说明缺口。
- 区分真实数据、情景测算与假设；不造数。预测与收益必须有假设及验证边界。

用于分析决策的页面连接证据→发现→解释→建议；保留期间、比较对象、样本/分母及来源。区分已证实原因、候选原因、证据缺口与验证办法；鱼骨图不构成因果证据，相关不等于因果。考虑季节性、分组构成与样本偏差。证据不足时给出待验证问题，不强造洞察。

### 数据图表选择

| 目的 | 适合的图 | 限制 |
|---|---|---|
| KPI/目标 | 数字、子弹图、实际/目标对比 | 好坏颜色按内容定义 |
| 时间变化 | 折线、柱线、小多图 | 缺失不补零，不完整期间标记 |
| 排名/差距 | 排序条形、点图、哑铃图 | 条形通常零起点，尺度一致 |
| 构成/占比 | 堆叠条、少分类环形 | 同一总体、分类可相加、分母明确 |
| 分布 | 直方、箱线、分位数 | 标样本与范围，不只报均值 |
| 关系 | 散点、分层图 | 标样本，相关不是因果 |
| 差异贡献 | 瀑布、贡献条、Pareto | 组成项可加且对上总差异 |

不凑齐图种。轴、图例、单位、期间与样本可读；避免3D、无必要双轴和只靠红绿区分。精度与源数据相称，跨页数值一致。

## 成品与检查

按约定比例，默认16:9。无模板时可从标题32–40pt、正文18–24pt、主数字32–52pt、注释12–14pt起步，按展示场景检查阅读距离。优先删减内容，再调整字号。

统一标题层级、色值、字体与回退、网格、页边距、页码和来源格式。用户模板优先。照片、作品和产品截图保持比例；正文、表格、数据图表及要求可编辑的示意图保留原生对象。插画中不承载必须编辑的正式文字。

建议和计划按实际用途补充依据、优先级、执行角色、时间与验证方法；教学可使用练习与反馈，故事分享可用点题。负责人和日期未知时不杜撰。

交付检查：

1. 页数、比例、语言、内容与选定风格对应；封面、收尾及各自是否生成背景与配置一致。
2. 内容满足主题、受众与演示目标，叙事连贯；没有强塞无关的经营分析章节。
3. 专名、引语、事实及来源已核对；有数字时复算，核对百分比/百分点、分母、期间、单位与样本。
4. 真实素材与生成插画用途清楚，未将示意内容表述为实证。
5. 逐页实际渲染查看，修复遮挡、溢出、裁切、图例、字体及对比度。
6. PPTX存在且能被文稿工具重新读取，原生内容可编辑；只声明实际检查过的兼容性，不声称在未打开的PowerPoint里验收。
7. 图标模式、风格、右上角标识/留空及范围一致；Logo使用正式素材且未变形。
8. 默认交付PPTX；用户要求PDF/图片/分析附件时再导出，临时文件不混入成品。

资料不足、工具失败或文件损坏时说明具体范围和下一步；不以截图拼接、空文件或提纲冒充正式PPT。无法渲染时如实说明视觉检查尚未完成。
